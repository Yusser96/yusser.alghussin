# yusser.alghussin

Personal academic website of Yusser Al Ghussin — PhD student at DFKI (TRAILS) and Saarland University.

Live at: https://yusser96.github.io/yusser.alghussin/

## Editing

- `index.html` — all content (research, publications, software, service)
- `style.css` — styling
- **Photo:** drop a square image at `assets/profile.jpg` and it will replace the "YA" monogram automatically.

Plain static HTML/CSS, no build step. Push to `main` and GitHub Pages redeploys.
